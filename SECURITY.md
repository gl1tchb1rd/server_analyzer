# Security

Server Analyzer verarbeitet potentiell sensible Ermittlungs- und Beweismitteldaten. Bitte veröffentliche **keine echten Serverimages, Journaldateien, Mailboxen, Zugangsdaten oder Ermittlungsberichte** in öffentlichen Issues.

Sicherheitsrelevante Fehler sollten zunächst ohne Echtdaten beschrieben werden. Falls Reproduktionsdaten erforderlich sind, nutze ausschließlich synthetische oder vollständig anonymisierte Testdaten.

Die Anwendung ist als read-only Offline-Analyzer konzipiert. Sie führt keine administrativen Aktionen gegen das untersuchte System aus.
