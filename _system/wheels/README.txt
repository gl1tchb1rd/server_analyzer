Optionaler Offline-Paketordner
=============================

Wenn der Dienstrechner beim ersten Start keine freigegebene pip-Paketquelle erreichen kann,
können hier passende Windows-Wheels fuer die in ../requirements.txt aufgefuehrten Pakete
abgelegt werden. Der Starter versucht dann zunaechst eine vollstaendig lokale Installation.

Die Auswertung selbst benoetigt keine Internetverbindung.
