# Lizenztexte

Die Standard-Source-Distribution enthält keine Drittanbieter-Wheels oder Qt-Binärdateien. Maßgeblich für nachgeladene Pakete sind die mit der konkret installierten Version gelieferten Lizenz- und Notice-Dateien.
